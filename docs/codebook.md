## 판정 규칙
- **칸 합치기:** 소컷이 겹치거나 한 덩어리로 붙어 있으면 한 행으로 두고 내용에 ①②③으로 적음
- **말풍선 조각:** 칸 위에 걸쳐 잘린 말풍선·효과음 조각은 앞뒤 칸에 붙임. 독립된 말풍선만 따로 '말풍선' 행
- **크레딧·로고:** 회차 끝 크레딧은 제외, 회차 처음 로고는 '타이틀'
- **새 값:** 코드표에 먼저 추가하고 쓰기

## 5컷 묶음 (5컷 리듬)
장면 안 그림 컷을 5컷 기준으로 묶되 3~7컷 허용. 2컷 이하 꼬리는 같은 장면의 앞 묶음에 합침. 장면 전체가 2컷 이하면 단독 묶음(연출명 비워도 됨).

| 항목 | 값 | 기준 | 근거 |
|---|---|---|---|
| 연출명 | Push-in, Pull-out, Hold, Fragmented Reveal, Reaction Framing, Delayed Reveal, Dramatic Irony, Insert, Shot / Reverse Shot, POV, Stretch, Bridge, Walk and Talk, Montage, Color Shock | | 영화 편집 관습 |
| 거리 흐름 | 좁혀감 / 넓혀감 / 좁혔다 넓힘 / 넓혔다 좁힘 / 교차 / 유지·넓게 / 유지·좁게 / 단일 | 샷 크기 순위(설정0~디테일5)의 변화. 범위 1 이하 유지, 방향 전환 2번 이상이면 교차(처음·끝 차가 2 이상이면 좁혀감·넓혀감) | 커버리지의 원경→근경, Block의 공간 대비 |
| 템포 | 빠름 / 보통 / 느림 | 묶음 길이 ÷ 그림 컷 수 ÷ 폭. 두 작품 244묶음 3등분(1.24, 1.63) | 웹툰 스크롤 거리·여백, 영화 샷 길이 |
| 서사 형태 | 무정점 / 정점 선행 / 중간 정점 / 끝 정점 / 정점 연속 | VNG의 P 위치·개수 | Neil Cohn 시각서사문법 (E)(I(Pr))P(R) |
| 정보 흐름 | 즉시 공개 / 지연 공개 / 조각 공개 / 독자 선행 / 흐름 유지 | 공개형 연출명은 대응, 그 외 '공개' 역할 컷의 위치 | 서스펜스·서프라이즈, 반응 선행 편집 |
| 색 흐름 | 유지 / 점진 변화 / 교대 / 명암 급변 / 강조 출현 | 묶음 안 덩어리 색 변화 | Bruce Block 대비와 친화 |
| 감정 곡선 | 평탄 / 상승 / 하강 / 산형 / 골형 | 그림 컷 강도 변화 | Block 강도 그래프 |
| 연출 목적 | 몰입 유도 / 여운 / 감정 지속 / 궁금증 유발 / 충격 강조 / 긴장 고조 / 정보 강조 / 관계 대비 / 시점 동일시 / 장면 전환 / 시간 압축 / 정보 전달 | 연출명에서 기본값, 사람이 고칠 수 있음 | |
