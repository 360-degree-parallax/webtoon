# 말풍선 넣기 · 고치기를 한 자리에서: 기획 (2026-11-25)

## 1. 지금 무엇이 문제인가(재현)

| 동작 | 지금 일어나는 일 | 문제 |
|---|---|---|
| 에셋 › 말풍선 형태 누르기 | 새 말풍선을 넣음 → 화면 위쪽 **속성 서랍**이 열림 → 문구 칸에 커서 | 커서를 보여 주려고 **페이지가 맨 위로 튐**(측정: 스크롤 2034 → 0). 보던 컷과 누르던 에셋 목록이 화면 밖으로 사라짐. 서랍(높이 약 440px)이 캔버스를 가림 |
| 상황 막대 › 문구 고치기 | 같은 속성 서랍을 열고 문구 칸에 커서 | 위와 같은 튐·가림. 서랍에는 문구·형태·연결·꼬리·크기만 있음. 글꼴·꾸밈·색·테두리·글에 맞추기는 상황 막대에, 스타일 적용·잠금은 또 다른 곳에 흩어져 있음 |
| 캔버스에서 더블클릭 | 말풍선 위에 바로 글칸(인라인) | 빠르지만 문구만 고칠 수 있음 |

**원인:** 고치는 곳이 세 군데(속성 서랍 · 상황 막대 · 인라인)로 나뉘어 있다. 그중 속성 서랍은 화면 맨 위에 있고, 커서를 넣을 때 스크롤을 막지 않는다.

## 2. 원칙

1. **누른 자리에서 끝낸다.** 에셋을 누르면 에셋이 있는 오른쪽 패널 안에서 바로 고친다. 화면(캔버스·패널)은 움직이지 않는다.
2. **고치는 곳은 한 곳.** 에셋에서 넣은 직후와 「문구 고치기」는 같은 「편집 카드」를 연다. 더블클릭 인라인은 빠른 글 수정용으로 남기고 카드와 실시간으로 맞춘다.
3. **보이는 대로 고른다.** 형태는 드롭다운이 아니라 그림 격자로 보여 주고, 색은 동그라미로 보여 준다.
4. **고르면 바로 반영한다.** 「적용」 버튼 없이 고치는 대로 캔버스에 보인다(타자는 0.3초 묶음). Ctrl+Z로 되돌린다.

## 3. 화면 구조

```
┌ 오른쪽 패널(에셋 자리) ───────────────────────┐
│ ┌ 편집 카드 · 고른 식자가 있을 때 위에 붙음 ──┐ │
│ │ 말풍선 · 3컷  [@준 ▾]            [⋯] [×]   │ │
│ │ ┌ 문구 ─────────────────────────────────┐   │ │
│ │ │ 이 시간에 누구지?                      │   │ │
│ │ └───────────────────────── 9자 · 2줄 ───┘   │ │
│ │ 글자  [가][가][가]  B I U  ●글자 ○테두리 −+ │ │
│ │ 형태  (○)(◇)(☁)(✱)(□)(⌒)…  그림 격자      │ │
│ │ 상자  크기 ━━●━━ 100%  [글에 맞추기]       │ │
│ │ 꼬리  [표시 ✓] [방향 처음대로]  연결 [두 칸]│ │
│ │ 배치  [←][↔][→]  회전 0° [없애기]          │ │
│ └─────────────────────────────────────────────┘ │
│ 다른 형태로 바꾸기 ▸ (아래 에셋 격자, 누르면 바꿈) │
│ [에셋 격자 …]                                   │
└────────────────────────────────────────────────┘
```

- 카드는 오른쪽 패널 맨 위에 붙는다(sticky). 아래 에셋 목록은 그대로 스크롤된다.
- 고른 식자가 없으면 카드는 접혀 사라지고 에셋 목록만 보인다.
- 「⋯」 메뉴: 스타일 적용 ▾ · 복제 · 겹침 순서 · 잠그기 · 지우기.
- 상황 막대는 가볍게 줄인다: 「말풍선 · 문구 앞부분 · 형태 이름 · 문구 고치기 · 스타일 적용 ▾」. 「문구 고치기」를 누르면 카드의 문구 칸으로 커서가 간다.
- 속성 서랍은 고급 설정(정렬 수치·기록)용으로 남기고, 자동으로 열지 않는다.

## 4. 상호작용 규칙

| 동작 | 결과 |
|---|---|
| 에셋 › 말풍선 형태(고른 말풍선 없음) | 고른 컷에 새 말풍선(기존 말풍선과 겹치지 않는 빈자리, 없으면 가운데) → 선택 → 카드가 열리고 문구 칸이 비어 「대사를 입력하세요」 자리표시 → 커서(스크롤 없이) |
| 에셋 › 말풍선 형태(말풍선 고른 상태) | 새로 넣지 않고 형태만 바꿈(지금 동작 유지). 카드 형태 격자 표시도 바뀜 |
| 컷을 고르지 않고 에셋 누르기 | 지금 화면 가운데에 보이는 컷에 넣음(「먼저 컷을 고르세요」 대신) |
| 상황 막대 「문구 고치기」 · Enter | 카드 문구 칸에 커서, 전체 선택 |
| 캔버스 더블클릭 | 말풍선 위 인라인 글칸(빠른 수정). 카드 문구 칸도 같이 바뀜 |
| 카드에서 타자 | 0.3초 뒤 캔버스에 반영. 글이 길어지면 상자가 늘어나고, 40자를 넘으면 「나누기 제안: 두 말풍선으로」 |
| 화자 칩 [@준 ▾] | 인물 목록 · 「나레이션으로 바꾸기」 · 「속마음(점선)으로」. 컷 글의 그 줄이 바뀜 |
| Esc | 카드 칸에서 나와 캔버스로 포커스(선택 유지). 한 번 더 누르면 선택 해제 |
| 다른 식자를 누름 | 카드 내용이 그 식자로 바뀜(같은 자리, 패널 움직임 없음) |
| 새 말풍선이 화면 밖 | 캔버스만 부드럽게 그 위치로(오른쪽 패널은 그대로) |

|---|---|---|---|
| 문구 | ○(여러 줄) | ○ | ○(한 낱말) |
| 화자 | 인물 · 나레이션으로 · 속마음 | 말풍선으로 바꾸기 | – |

| 상자 크기 · 글에 맞추기 | ○ | ○ | 크기 |

## 6. 구현 순서(제안)

1. **튐 고치기(작음):** 넣은 뒤 서랍을 자동으로 열지 않고, 커서는 `focus({preventScroll:true})`. 이것만으로 「위로 딸려 가는」 문제는 사라진다.
2. **편집 카드(말풍선):** 오른쪽 패널 위 sticky 카드. 문구 실시간 반영, 형태 격자, 글자 도구, 상자·꼬리·연결·배치. 「문구 고치기」·Enter를 카드로 연결. 상황 막대 정리.
3. **나레이션·효과음 카드:** 같은 틀에 종류별 항목.
4. **화자 바꾸기 · 나누기 제안 · 빈자리 배치:** 컷 글을 고치는 기능이라 마지막에 둔다.

## 7. 확인 기준

- 에셋에서 말풍선을 넣을 때 페이지 스크롤과 오른쪽 패널 스크롤이 0px 변한다.
- 넣기 → 타자 → 형태 바꾸기 → 글에 맞추기를 오른쪽 패널 안에서 손을 떼지 않고 끝낸다.
- 「문구 고치기」와 에셋 넣기가 같은 카드, 같은 위치를 연다.
- 더블클릭 인라인 수정과 카드 문구가 항상 같다.
- 모든 변경은 Ctrl+Z 한 번에 한 단계씩 되돌린다.
