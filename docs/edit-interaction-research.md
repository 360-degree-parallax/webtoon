# 편집 화면 조작: 다른 툴과 다른 점 (2026-11-24)

비교 대상: 피그마 · 캔바(미리캔버스·망고보드도 거의 같은 관례) · 클립스튜디오(말풍선·텍스트) · 포스타입 에디터.
우리 쪽은 편집 화면을 Playwright로 직접 눌러 확인했다(기본 예시 원고, 말풍선·나레이션 대상). "된다/안 된다"는 모두 실제로 눌러 본 결과다.

## 2. 다른 툴을 쓰던 작가가 바로 걸리는 것 (영향이 큰 순)

1. **Ctrl+A가 화면 글자를 다 선택해 버림.** 피그마·캔바에 익숙하면 가장 먼저 누르는 키다. 지금은 메뉴·버튼 글자까지 파랗게 칠해져 고장 난 것처럼 보인다.
2. **복사·붙여넣기·복제가 없음(식자).** 같은 모양 말풍선을 여러 개 만드는 게 웹툰 식자의 기본 작업인데, 지금은 매번 새로 넣고 형태·크기를 다시 맞춰야 한다. 우리 「크기 적용 / 형태 적용」(속성 서랍 › 글자)이 일부 대신하지만, 찾기 어렵다.
3. **Shift의 뜻이 다름.** 다른 툴은 Shift+**클릭**=고르기에 더하기, Shift+**끌기**=가로·세로 고정이다. 우리는 Shift를 누르고 누르는 순간 고르기에 더해지고 끌기가 막힌다. 말풍선을 같은 높이로 옆으로 옮기려다 아무 일도 안 일어난다.
4. **여러 개 골라도 함께 못 옮김.** 고르기까지는 되는데 끌면 하나만 움직인다. 할 수 있는 건 정렬 버튼뿐.
5. **맞춤선이 없음.** 말풍선을 컷 가운데나 다른 말풍선과 나란히 놓을 때 눈대중이다. 캔바·피그마는 끄는 동안 분홍 선이 뜨고 붙는다.
6. **빈 곳 끌어 여러 개 고르기가 없음.** 빈 곳을 끌면 아무 일도 없다(컷 고르기만 풀림).
7. **겹침 순서·그룹·회전 없음.** 효과음 위에 말풍선을 올리거나, 기운 말풍선(외침)을 만들 수 없다. 클립스튜디오는 말풍선 회전이 기본 조작이다.
8. **레이어 패널에서 끌어 순서 바꾸기 없음.** 컷 순서는 우클릭 메뉴로 한 칸씩만.

## 3. 다른 툴과 다르지만 우리가 나은 것 · 일부러 다른 것

- **식자 자동 배치:** 글에서 말풍선·나레이션·효과음이 자동으로 컷에 놓인다. 다른 툴은 전부 손으로 놓는다.
- **컷 간격 손잡이:** 컷 사이를 끌어 px로 간격을 정한다(웹툰 호흡 조절). 피그마·캔바에는 개념이 없다.
- **변 손잡이:** 글자 크기는 그대로 두고 상자만 늘린다. 피그마의 텍스트 박스 고정 폭과 비슷한데, 말풍선 모양까지 같이 늘어나는 건 우리만 된다.
- **상황 막대:** 고른 것에 맞는 도구만 위에 뜬다(피그마 오른쪽 패널 · 포스타입 고른 것 위 도구 묶음의 중간).
- **읽기 모드(휴대폰 폭):** 웹툰 결과를 바로 휴대폰 크기로 본다. 다른 툴은 따로 미리보기를 켜야 한다.

## 4. 제안 (작은 일부터)

**바로 (반나절 안팎)**
1. Ctrl+A: 편집 화면에서는 고른 컷의 식자 전체(컷이 없으면 화면에 보이는 씬의 식자)를 여러 개 고르기로. 브라우저 글자 선택은 막음.
2. Ctrl+C / Ctrl+V / Ctrl+D: 식자 복사·붙여넣기·복제(형태·크기·글꼴·꾸밈 그대로, 약간 비켜서). 다른 컷을 고르고 붙여넣으면 그 컷에.
3. Shift 나누기: Shift+클릭=여러 개 고르기(지금처럼), Shift+끌기=가로·세로 고정. 누를 때가 아니라 놓을 때 클릭인지 끌기인지 판단.
4. Enter=글자 고치기(더블클릭과 같은 상자), Tab / Shift+Tab=같은 컷 안 다음·이전 식자.

**다음**
5. 여러 개 함께 끌기(고른 식자 전부 같은 만큼).
6. 맞춤선: 컷 가운데·좌우 가장자리·다른 식자 가운데에 4px 안이면 붙고 선 표시. Ctrl(⌘) 누르면 끔.
7. Alt+끌기 복제.
8. 빈 곳 끌어 사각형 고르기(식자만).

**그다음**
9. 식자 겹침 순서(Ctrl+] / [), 회전 손잡이(말풍선·효과음, Shift로 15° 단위).
10. 레이어 패널 끌어 순서 바꾸기(컷 · 같은 컷 안 식자).
11. 그룹은 웹툰 식자에서 쓸 일이 적어 보류(연결 말풍선은 이미 「이어진 말풍선」으로 처리).
