# ROUGH UX/UI · 유저플로우 최적화 기획 (클립스튜디오 · 피그마 참고)

작성 2026-11-22 · 대상: `rough/index.html` 현재 배포본(내보내기 추가 후)

## 0. 한 줄 요약

지금 ROUGH는 **7단계 탭을 순서대로 넘기는 폼 도구**예요. 클립스튜디오와 피그마는 **작업 공간 하나에 패널을 붙여 놓고 오가는 캔버스 도구**고요.
그래서 핵심은 화면을 더 만드는 게 아니에요. 단계를 **준비 · 쓰기 · 연출** 세 작업 공간으로 줄이고, 연출 작업 공간을 피그마식 캔버스(레이어·속성·소재 패널, 도구막대, 단축키)로 키우는 거예요.

---

## 1. 현재 진단

### 1-1. 지금 흐름

```
1 캐릭터 → 2 세계관 → 3 구성(AI) → 4 씬(컷 글쓰기) → 5 콘티(패턴 매칭·미리보기) → 6 작화(NovelAI 프롬프트) → 7 편집(페이지) → 내보내기
                                                                              ↘ DB(별도 조회)
```

### 1-2. 문제점 (화면에서 확인한 것)

| # | 문제 | 근거 | 영향 |
|---|---|---|---|
| P1 | **첫 화면이 6단계 '작화'** | `showView` 기본값이 `nai` | 처음 온 사람이 어디서 시작할지 모름 |
| P2 | 단계가 7개이고 모두 같은 무게의 탭 | 상단 탭 1~7 | 준비 단계(캐릭터·세계관)를 매번 지나가야 할 것처럼 보임 |
| P3 | **콘티와 편집이 따로** | 5 콘티(미리보기·패턴) ↔ 7 편집(페이지) | 같은 컷을 두 화면에서 다르게 봄. 칸 크기는 편집에서만, 패턴 바꾸기는 콘티에서만 |
| P4 | 작화(NovelAI)가 콘티와 편집 사이에 끼어 있음 | 6 작화 | 외부 생성 작업이 흐름을 끊음. 이미지 등록 위치가 씬·작화 두 군데 |
| P5 | 씬 선택기가 화면마다 반복 | 콘티·작화의 `scbar`, 씬의 왼쪽 목록, 편집의 목차 | 지금 어느 씬을 보는지 헷갈림 |
| P6 | 저장 버튼이 두 군데 | 헤더 'SVG 저장/PNG 저장'(콘티 전용) + 편집 '내보내기' | 무엇이 저장되는지 다름 |
| P7 | 편집 캔버스를 확대·축소·이동할 수 없음 | 칸 안 그림만 확대 가능 | 긴 세로 스크롤에서 전체 리듬을 못 봄 |
| P8 | 레이어 개념이 없음 | 목차는 씬·컷만, 식자·효과는 캔버스에서만 고름 | 겹친 말풍선을 고르기 어렵고, 숨김·잠금이 없음 |
| P9 | 만드는 도구가 없음 | 말풍선·효과음은 씬 글에서만 생김 | 캔버스에서 바로 말풍선 추가·칸 나누기가 안 됨 |
| P10 | 작품 = 브라우저 한 개 | localStorage 저장, 작품·화 구분 없음 | 다른 기기·여러 화 작업 불가. 지우면 사라짐 |
| P11 | 단축키가 편집 화면에만 몇 개 | Ctrl+Z, 방향키, Esc | 반복 작업이 느림 |
| P12 | 미리보기가 PC 폭 | 690px 캔버스를 데스크톱에서만 봄 | 실제 독자 화면(모바일 세로)으로 읽어 볼 수 없음 |

### 1-3. 잘 되고 있는 것 (유지)

- 편집 화면의 3단 구성(목차 · 캔버스 · 속성)은 이미 피그마 UI3와 같은 뼈대예요.
- 캔버스 위 직접 조작(칸 변·꼭짓점, Ctrl+휠 그림 확대, 간격 손잡이)은 클립스튜디오의 칸 테두리 도구와 감각이 같아요.
- 씬 글쓰기의 기호 문법(`[ ]` 식자, `@` 대사, `-~-` 효과음)은 클립스튜디오의 스토리 에디터처럼 글로 빠르게 넣는 경로라 강점이에요.
- 내보내기(PNG · 피그마 SVG · 클립스튜디오 PSD)가 이제 한 메뉴에 모였어요.

## 3. 목표 유저플로우

### 3-1. 7단계를 작업 공간 3개로

```
[준비]  작품 설정 · 캐릭터 · 세계관 · 소재      ← 한 번 만들고 가끔 돌아옴 (피그마 에셋)
   ↓
[쓰기]  구성(AI) → 씬 글쓰기                     ← 글로 빠르게 (클립스튜디오 스토리 에디터)
   ↓
[연출]  콘티 + 편집 + 작화를 한 캔버스에서        ← 핵심 작업 공간 (피그마 캔버스 + 클립스튜디오 팔레트)
   ↓
[내보내기] PNG · 피그마 SVG · 클립스튜디오 PSD · 읽기 모드 공유
```

- **콘티 = 연출 캔버스의 '러프' 보기**, **편집 = '완성본' 보기**. 지금 편집 화면의 완성본/러프 토글을 그대로 넓혀 두 화면을 합쳐요.
- 패턴 고르기(콘티의 "이렇게 읽었어요", 다른 안 ‹ ›)는 씬을 고르면 속성 패널에 나와요.
- **작화(NovelAI)** 는 단계에서 빼고, 컷을 고르면 속성 패널의 '작화' 탭에 프롬프트 복사·바탕 PNG·이미지 등록이 나와요. 이미지 등록 위치를 하나로 모아요.
- DB는 소재 패널의 '레퍼런스' 탭에서 검색해 끌어오고, 전체 표는 지금처럼 따로 둬요.

### 3-2. 첫 방문과 다시 방문

| 상황 | 지금 | 바꾼 뒤 |
|---|---|---|
| 처음 열었을 때 | 6단계 작화가 열림 | **홈**: 새 작품 / 예시 작품 열기 / 최근 작품. 예시는 녹빛자정 1씬 |
| 새 작품 | 캐릭터부터 순서대로 | 제목·장르만 받고 바로 **쓰기**. 캐릭터는 대사에 `@이름`이 처음 나올 때 "캐릭터로 만들까요?" |
| 다시 열었을 때 | 마지막 탭 | 마지막 작업 공간 + 마지막 씬·컷 선택 상태 그대로 |
| 다 만들고 나서 | 편집 › 내보내기 | 상단 오른쪽 **내보내기** 하나(어느 화면에서나). 화·씬 범위를 고름 |

### 3-3. 핵심 작업 루프 (연출 공간)

```
씬 고르기(왼쪽) → 컷 고르기(캔버스) → 속성에서 조정(오른쪽)
   ├ 칸: 크기·모양·간격·배경 전환
   ├ 그림: 레퍼런스 바꾸기 · 이미지 등록 · 확대/이동 · 작화 프롬프트
   └ 식자: 문구·말풍선 형태·꼬리·크기
→ 읽기 모드(모바일 폭)로 확인 → 다음 씬
```
지금은 이 루프가 씬(4) · 콘티(5) · 작화(6) · 편집(7) 네 화면에 흩어져 있어요. 한 화면에서 돌게 하는 게 목표예요.

## 4. 연출 작업 공간 화면 설계

```
┌ 상단 ─────────────────────────────────────────────────────────────────────┐
│ ROUGH · 작품명 ▾ · 화 ▾   [준비][쓰기][연출]      러프|완성본   ↶ ↷  읽기  공유  내보내기 │
├───────────┬──────────────────────────────────────────────┬────────────────┤
│ 왼쪽 패널  │                  캔버스                       │ 오른쪽 속성     │
│ [레이어]   │   ┌ 씬 1 ┐  ┌ 씬 2 ┐  ┌ 씬 3 ┐ …            │ 선택에 따라:    │
│ [소재]     │   │ 컷   │  │      │  │      │               │ · 씬: 패턴·리듬 │
│            │   │ 컷   │  │      │  │      │  (씬=프레임,   │ · 컷: 칸/그림/작화│
│ 씬1        │   └──────┘  └──────┘  └──────┘   가로 배치 또는 │ · 식자: 문구·형태│
│  컷1 ▸     │                                 세로 이어 보기)│                 │
│   칸 👁🔒  │                                               │                 │
│   그림     │                                    [미니맵]   │                 │
│   말풍선1  │                                               │                 │
├───────────┴───────────── 아래 도구막대 ───────────────────┴────────────────┤
│  V 선택   H 손   F 칸 나누기   B 말풍선   T 텍스트   S 효과음   C 댓글   │  100% ▾   │
└───────────────────────────────────────────────────────────────────────────┘
```

### 4-1. 패널별

- **왼쪽 레이어**: 씬 › 컷 › (칸 · 그림 · 효과 · 식자). 눈(숨김)·자물쇠(잠금)·이름 바꾸기·끌어서 순서 바꾸기. 내보내기 레이어 구조(SVG·PSD)와 이름을 똑같이 맞춰서, 피그마나 클립스튜디오에서 열어도 같은 구조로 보이게 해요.
- **왼쪽 소재**: 캐릭터(외형·태그·대표 이미지), 배경, 효과음 소재 팩, 말풍선 스타일, DB 레퍼런스 검색. 캔버스로 끌어다 놓기:
  - 캐릭터 → 컷의 등장인물 지정
  - 레퍼런스 → 컷 그림 교체
- **오른쪽 속성**: 지금 편집 패널을 그대로 쓰고, 탭을 **칸 / 그림 / 작화 / 식자**로 정리해요. 씬을 고르면 콘티의 '이렇게 읽었어요' 카드와 다른 안 ‹ ›이 나와요.
- **캔버스**:
  - Ctrl/⌘+휠 확대·축소, Space+드래그 이동
  - Shift+1 전체 보기, Shift+2 선택한 것 보기
  - 칸 안 그림 확대는 지금처럼 그림을 더블클릭해 들어간 상태에서만 동작(피그마 이미지 크롭 모드)해서 캔버스 확대와 충돌하지 않게 해요.
- **미니맵**: 웹툰 전체 세로 띠 + 지금 보는 영역 상자(클립스튜디오 내비게이터). 칸 간격·배경 전환의 리듬을 한눈에 봐요.

### 4-2. 도구막대와 단축키

| 키 | 도구·동작 | 참고 |
|---|---|---|
| V | 선택 | 피그마·클립 공통 |
| H / Space 누른 채 | 손(캔버스 이동) | 공통 |
| F | 칸 나누기: 칸 위로 선을 그어 둘로 자름 | 클립 칸 테두리 자르기 |
| B | 말풍선: 클릭한 자리에 추가, 끌면 꼬리 | 클립 말풍선 도구 |
| T | 텍스트(나레이션) | 공통 |
| S | 효과음: 소재 팩에서 고르기 | 클립 소재 |
| C | 댓글 | 피그마 |
| Ctrl/⌘ + D | 복제(컷·식자) | 공통 |
| Ctrl/⌘ + G / Shift+Ctrl/⌘ + G | 묶기 / 풀기(두 칸 연결 말풍선 등) | 공통 |
| Alt/⌥ + 끌기 | 복제하며 이동 | 공통 |
| Ctrl/⌘ + / (또는 K) | 명령 팔레트 | 피그마 빠른 동작 |
| [ / ] | 이전·다음 컷 | |
| Ctrl/⌘ + [ / ] | 이전·다음 씬 | |
| Shift + 1 / 2 | 전체 보기 / 선택한 것 보기 | 피그마 |
| P | 읽기 모드 | 피그마 Present |

`?` 키로 단축키 목록을 보여 줘요.

### 4-3. 쓰기 작업 공간

- 왼쪽 씬 목록, 가운데 글(지금 씬 화면), 오른쪽에 **실시간 콘티 썸네일**. 글을 쓰는 동안 오른쪽에 러프가 바로 바뀌어요. 지금은 콘티 탭으로 넘어가야 보여요.
- 줄글 붙여넣기 → 컷 나누기는 유지해요. 대사만 모아 보는 **대본 보기**(클립스튜디오 스토리 에디터처럼)를 추가하고, 내보내기의 '대사 목록.txt'와 같은 형식으로 맞춰요.

### 4-4. 준비 작업 공간

- 캐릭터·세계관을 한 화면 두 탭으로 합쳐요. 카드 그리드(피그마 에셋 보기)로 보여 주고, 누르면 오른쪽에서 상세를 편집해요.
- 보관함(다른 작품에서 불러오기)은 피그마 '라이브러리'처럼 "팀 라이브러리" 개념으로 이름을 바꿔요.

## 5. 데이터·저장 구조

| 지금 | 바꾼 뒤 |
|---|---|
| 브라우저 localStorage 하나 = 작품 하나 | **작품 파일**: `작품 › 화[] › 씬[] › 컷[]` JSON 하나 + 이미지 |
| 다른 기기로 옮기기: 보관함 파일 내보내기 | 작품 파일 열기/저장(.rough.json, 이미지 포함 zip). 나중에 클라우드 저장 |
| 실행 취소는 편집 화면에서만 | 전 화면 공통 실행 취소 + **버전 저장**(이름 붙여 저장, 되돌리기) |

이 구조가 있어야 홈(최근 작품), 화 전환, 협업 댓글이 가능해요. 먼저 '작품 파일 저장/열기'만 만들고 localStorage는 자동 저장 캐시로 남기면, 지금 쓰는 데이터를 그대로 옮길 수 있어요.

## 7. 확인 방법 (지표)

- **첫 컷까지 걸린 시간**: 처음 연 순간부터 첫 러프 컷이 화면에 나올 때까지(목표: 1분 이내, 예시 작품이면 0초).
- **화면 이동 횟수**: 씬 하나를 완성본까지 만드는 동안 탭을 바꾼 횟수(지금 최소 4번 → 목표 0~1번).
- **내보내기 성공률**: 내보내기를 누른 횟수 대비 파일 저장 완료.
- **되돌리기 비율**: 칸·식자 조작 뒤 바로 실행 취소한 비율. 높으면 직접 조작이 예측과 다르다는 신호.
- 사용성 테스트 5명: "새 작품을 만들어 씬 하나를 PSD로 내보내기"를 시키고 막히는 지점을 기록.
