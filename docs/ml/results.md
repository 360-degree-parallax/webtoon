### 샷 재검토 큐

- 파일: `docs/ml/shot-audit.csv`
- 모델이 확신하는데(1위 확률이 높고) 사람 라벨 확률은 낮은 컷 300개를 그 차이가 큰 순서로 정렬
- 위 4컷을 직접 보니:
  - 1·3번은 얼굴 클로즈업인데 '중경'으로 붙어 있음 → 라벨 오류
  - 2·4번은 경계 사례(디테일/클로즈업, 중경/전경)
- 이번 앵글 재검수처럼 사람이 이 목록만 보면 됨

## 샷 재검수 결과 (시트 리비전 177)

- 재검토 큐 300컷을 원본으로 하나씩 봄 → **178컷(59%) 사람 라벨 정정**
  - 많은 순: 전경→중경 48, 중경→클로즈업 23, 클로즈업→중경 23, 중경→전경 17, 전신→중경 15, 전신→전경 13, 디테일→클로즈업 8
  - 판단 기준(코드표 그대로 적용): 머리~가슴 위는 중경, 얼굴 중심(머리·어깨)은 클로즈업, 눈·입만 보이면 디테일, 인물이 공간 안에 작게 있으면 전경
- 나머지 122컷은 사람 라벨을 유지함. 경계 사례이거나, SD·화면 인서트·여러 칸 묶음처럼 모델이 범주를 잘못 본 경우
- **컷 이미지가 비어 있거나 잘못 잘린 4컷:** DN-06-117, DN-06-118, DN-07-017, MD-08-028. 컷 이미지 파일을 다시 확인해야 함
- **효과 측정:** 재검토하지 않은 3,368컷만 따로 평가. 고친 컷은 모델 제안 쪽으로 바뀌어 점수가 부풀므로 뺌

  | | 전체 | 재검토 안 한 3,368컷 |
  |---|---|---|
  | 고치기 전 라벨 | 66.1% | 72.0% |
  | 고친 라벨 | 73.0% | **74.3%** |

  - 전체 73.0%에는 고친 컷이 들어가 있어 부풀려진 값
  - 학습 라벨이 깨끗해진 만큼 실제로 오른 폭은 **+2.3%p**
- 결과적으로 샷 라벨 오류율이 이전 생각보다 높았음: 의심 300컷 중 59%
  - 다음 300컷(확률 차이 다음 순위)을 같은 방식으로 보면 추가로 정정될 가능성이 큼


## 판정 화면 (상단 「판정」 버튼)

- 상단 DB 버튼 옆 「판정」(남은 수 배지, 휴대폰에서도 보임). 모델이 사람 라벨과 어긋난다고 본 컷을 하나씩 보여 주는 화면. 선택지는 4개(지금 값 + 모델 확률 상위)이고, 애매하면 '보류'를 누르고 메모를 남김
  - 단축키: 1~4 고르기 · 5 보류 · ←/→ 이동 · 메모는 Ctrl+Enter로 저장
  - 큐: `rough/db/review-queue.json` = 샷 300(앞서 본 300컷 다음 순위) · 감정 150 · 역할 150. 만드는 법 `python3 tools/ml/make_review_queue.py`
  - '모델 확률 보기'는 기본 꺼짐. 선택지 순서는 모델 확률 순
- **결과 저장 위치:** 이 브라우저에만 저장됨(작업 파일에도 들어감). '결과 복사'나 '파일로 저장'으로 꺼내 Claude에게 주면 다음 순서로 처리:
  1. `python3 tools/ml/apply_review.py 판정.json`으로 바꿀 값을 시트 수정 묶음으로 만들어 시트·DB 사본에 반영
  2. 보류는 메모를 읽고 원본 컷을 다시 보며 해소
