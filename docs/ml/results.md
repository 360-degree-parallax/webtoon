## 샷 재검수 결과 (시트 리비전 177)

## 판정 화면 (상단 「판정」 버튼)

- 상단 DB 버튼 옆 「판정」(남은 수 배지, 휴대폰에서도 보임). 모델이 사람 라벨과 어긋난다고 본 컷을 하나씩 보여 주는 화면. 선택지는 4개(지금 값 + 모델 확률 상위)이고, 애매하면 '보류'를 누르고 메모를 남김
  - 단축키: 1~4 고르기 · 5 보류 · ←/→ 이동 · 메모는 Ctrl+Enter로 저장
  - 큐: `rough/db/review-queue.json` = 샷 300(앞서 본 300컷 다음 순위) · 감정 150 · 역할 150. 만드는 법 `python3 tools/ml/make_review_queue.py`
  - '모델 확률 보기'는 기본 꺼짐. 선택지 순서는 모델 확률 순
- **결과 저장 위치:** 이 브라우저에만 저장됨(작업 파일에도 들어감). '결과 복사'나 '파일로 저장'으로 꺼내 Claude에게 주면 다음 순서로 처리:
  1. `python3 tools/ml/apply_review.py 판정.json`으로 바꿀 값을 시트 수정 묶음으로 만들어 시트·DB 사본에 반영
  2. 보류는 메모를 읽고 원본 컷을 다시 보며 해소

- 한 작품 빼고 평가(3,658컷): **MAE 0.638 → 0.421, 순위상관 0.04 → 0.60**
- 글에 `{길게}` 등을 적으면 그 값이 여전히 우선
- **컷 간격은 글로 예측이 안 됨**(어떤 설정에서도 순위상관 ≈ 0, MAE는 '늘 중앙값'과 같음). 작품·작가 습관 영향이 큰 것으로 보임 → 엔진 간격 규칙(붙임·보통·쉼·큰 쉼)과 `{간격}` 문법은 그대로 둠

## ⑤ 글 → 말풍선 모양 (툴에 적용됨, 규칙)

- DB에는 말풍선 **개수**만 있고 모양 라벨이 없음. 상세 설명 글에서 '가시 풍선·점선 풍선·독백' 같은 말을 캐면 쓸 만한 예가 20개 안팎(대부분 '생각'은 대사 속 낱말)이라 모양 자체를 학습할 수 없었음
- 대신 학습된 감정·강도 모델 위에 규칙: 대사에 `{…}`·연기 메모가 없을 때만, 센 감정(강도 3)이면 분노→거친 원, 놀람·당황→찢어진 외침, 긴장→잘게 떨리는 원 / 회상→아련한 생각 / 강도 2 이상에 '?!'·'!!'→찢어진 외침. 씬 화면 오른쪽 칩에 '말풍선 … · 자동'으로 표시
- 모양을 제대로 학습하려면 판정 화면에 '말풍선 모양' 항목(말풍선 있는 컷 이미지를 보고 고르기)을 추가해 라벨을 모아야 함

## ⑦ 작가 취향 학습 (툴에 적용됨)

- 씬 글의 `{샷}·{앵글}·{길이}·{간격}`이 엔진 원래 값과 다르면 '엔진 X → 작가 Y'로 기록(씬 id:컷 자리:항목, 마지막 값만, 이 브라우저 `rough-prefs-log` · 작업 파일에도 들어감)
- 같은 엔진 값에서 **3번 이상 · 60% 이상** 같은 값으로 고쳤으면 다음부터 엔진이 그 값으로(이유: '내 취향 · 아이레벨 대신 탑뷰 (직접 고친 3번)'). 길이는 고친 비율의 평균으로 전체 배율(0.7~1.4배, 3번 이상)

- 다음 단계 후보: 여러 작가의 기록(작업 파일)을 모아 전체 모델 재학습에 가중치로 쓰기

## ⑧ 샷·역할 모델 (툴에 적용됨)

- 문제: 엔진 샷(패턴 컷 샷 + 규칙)은 DB 샷과 23.0% 일치로 '가장 흔한 값'(34.9%)보다 낮았음. 샷은 칸 모양·레퍼런스·작화 프롬프트(close-up 등)를 모두 좌우함
- 방법: 컷 글(+앞뒤 컷 0.5배) 글자 1~3그램 TF-IDF + 로지스틱 회귀(감정 모델과 같은 방식). 화면 인서트→디테일, SD→중경으로 엔진 샷 7종에 맞춤. 사람이 확인한 라벨 가중치 적용
- 한 작품 빼고 평가(3,668컷)

  | | 엔진(규칙) | **모델(적용)** | 가장 흔한 값 |
  |---|---|---|---|
  | 샷 | 23.0% | **47.8%** (한 단계 차이까지 71.6%, κ 0.32) | 34.9% |

## ⑨ 앵글 모델 (툴에 적용됨)

- 문제: 엔진 앵글 규칙(분노·결의 → 로우, 쓸쓸·당황 → 하이, 설정 컷 → 하이)은 로우라고 한 154컷 중 4.5%, 하이라고 한 68컷 중 7.4%만 맞아 전체 85.6%로 '항상 아이레벨'(90.7%)보다 낮았음
- 방법: 컷 글(+앞뒤 0.3배) 글자 n-그램 + 로지스틱 회귀(클래스 균형). 하이·로우는 확률이 **0.8 이상일 때만** 고르고 아니면 아이레벨. 탑뷰 12컷은 하이로 합쳐 학습. 작은 가중치(|w|<0.2) 버린 상태로 평가·내보냄

  | | 전체 정확도 | 로우 정밀도(고른 수) | 하이 정밀도(고른 수) |
  |---|---|---|---|
  | 엔진 규칙 | 85.6% | 4.5% (154) | 7.4% (68) |
  | 항상 아이레벨 | 90.7% | — | — |
  | **모델(문턱 0.8)** | **90.6%** | **50.0%** (24) | **29.4%** (17) |

- 재현율은 낮음(로우 9.4%, 하이 2.3%) — 확실한 경우만 고르는 쪽. 더 자주 쓰고 싶으면 `{로우앵글}` 지시
- 파일: `rough/angle-model.js`(157KB) · `python3 tools/ml/train_angle.py --export --th 0.8`. 브라우저 일치 200/200

## ⑩ 레퍼런스 고르기 (툴에 적용됨)

- 평가: 컷마다 다른 작품의 레퍼런스(fit=ok) 중 하나를 골라, 고른 레퍼런스 그림과 그 컷 실제 그림의 CLIP·DINOv2 코사인 유사도와 샷 일치를 잼(`tools/ml/eval_refs.py`, 샷·역할·감정은 한 작품 빼고 만든 예측)

  | 방법 | CLIP | DINOv2 | 샷 일치 |
  |---|---|---|---|
  | 무작위 | 0.713 | 0.421 | 19.8% |
  | **지금까지: 고른 패턴의 컷 그대로** | 0.722 | 0.424 | 31.1% |
  | 꼬리표 점수만(샷·앵글·역할·감정) | 0.737 | 0.455 | 48.7% |
  | 글 유사도만 | 0.745 | 0.468 | 36.5% |
  | **꼬리표 + 4 × 글 코사인(적용, 조각 상위 80개)** | **0.753** | **0.475** | **48.8%** |
  | 상한: 그림을 보고 고름 | 0.874 | 0.574 | 50.9% |

- '무작위 → 상한' 사이를 지금 방식은 6%만 메웠고, 적용한 방식은 약 25%를 메움
- 예: '창문을 두드리는 소리' → 창문 컷, '장미를 든 에드가' → 창가에 앉은 에드가 컷, '편지를 쥔다' → 편지를 든 남자 컷
- 사용자가 직접 고른 레퍼런스(편집 화면)는 여전히 우선
- 파일: `rough/ref-text.js`(레퍼런스 2,367컷의 글 조각 상위 80개, 1.4MB) · `python3 tools/ml/export_refs.py --k 80`
