# 정답 많이 붙이기 말고 다른 기술 6가지 시도 (2026-11-26)

평가는 모두 **한 작품을 빼고 나머지 8작품으로 학습해 뺀 작품을 맞히는 방식**(9작품, 그림 컷 6,706개). 모든 모델은 컨테이너 안에서만 실행, 원고 이미지는 밖으로 보내지 않음. 스크립트: `tools/ml/exp/`.

| # | 기술 | 결과 | 판단 |
|---|---|---|---|
| T1 | 사전학습 비전 모델 특징(깊이 Depth-Anything-V2, 포즈 ViTPose, 애니 인물 검출 메타) | 샷 68.6→68.8%, 앵글 macro-F1 0.427→0.431. 오차 범위 | **효과 없음.** 그림 임베딩(CLIP·DINO)이 이미 그 정보를 담고 있음 |
| T2 | 라벨 오류 찾기(confident learning) | 샷 의심 1,367컷(20%). 예전 재검수 300컷에서 의심 표시가 실제 정정과 맞은 비율 64%(의심 아님 46%), 정정의 80%를 잡음 | **쓸 만함.** 다음 샷 재검수 큐로. 감정은 74%가 의심이라 라벨 자체가 흔들림 |

| T4 | 자기지도 순서 모델(라벨 없이 컷 순서 학습) | 문맥 표현을 붙이면 샷 −2.0%p, 역할 −1.8%p. 다음 컷 샷 20.8%(가장 흔한 값 30.2%) | **효과 없음.** 84회차로는 너무 적음. 처음 52.9%가 나온 건 평가 작품 회차를 외운 누수였음(작품별로 다시 학습해 확인) |

| T6 | 제로샷(CLIP 글 프롬프트, 소형 VLM SmolVLM-256M) | CLIP 샷 21.4%(가장 흔한 값 29.9%). VLM 120컷 13.4%(대부분 '와이드') | **판정기로는 안 됨.** CLIP 앵글 상위 5%는 로우 12%·하이 35%로 무작위 5배지만, 우리 라벨로 학습한 모델(T1 기본, 균형 가중)이 로우 17%·하이 44%로 더 나음 |

## 실제로 붙일 것

1. **샷 재검수 큐 2차**: `label-noise.csv`의 샷 의심 상위부터(예전 재검수 300컷은 제외)
2. **판정 큐를 능동 학습 방식으로**: `tools/ml/make_review_queue.py`에 '1·2위 확률 차이가 작은 컷 + 군집별 하나씩' 고르기
3. **로우앵글 재검수(보류 #26) 큐**: 균형 가중 앵글 모델의 로우·하이 점수 상위 5%(각 335컷)부터. 무작위보다 6~7배 잘 걸림

## 적용 결과 (2026-11-26, 시트 리비전 223 / DB 2 리비전 11)

1. **샷 재검수 2차**: 라벨 오류 의심 상위 300컷(예전 300컷 제외)을 원본으로 봄 → **156컷(52%) 정정**, 그중 143컷이 모델 제안과 같음
   - 많은 순: 클로즈업→디테일 20, 중경→클로즈업 16, 전경→중경 14, 클로즈업→중경 12, 전신↔전경 각 10, 디테일→클로즈업 10
2. **앵글 재검수(보류였던 것)**: 균형 가중 앵글 모델의 로우·하이 점수 상위 5%씩 548컷(이미 확인한 컷 제외) → **138컷 정정**
   - 아이레벨→하이앵글 92, 아이레벨→로우앵글 43, 탑뷰→하이앵글 2, 로우앵글→아이레벨 1
   - 로우 큐 287컷 중 최종 로우앵글 55(19%), 하이 큐 261컷 중 최종 하이앵글 180(69%). 흔한 오류: 하늘·건물·샹들리에를 올려다본 컷, 방·책상·바닥을 내려다본 컷을 아이레벨로 둠
   - 두 시트 컷표 H·I열 294칸, DB 사본·cuts/index(.min).json·patterns·nai-stats 반영, 확인 기록(verified.json)에 Claude 판정 848건 추가(다음 학습 가중치 2배)
   - 효과(이번에 보지 않은 컷만으로 평가): 샷 71.9→73.3%(macro-F1 0.653→0.673), 앵글 87.7→88.4%(macro-F1 0.477→0.487)
3. **판정 큐 능동 학습**: `make_review_queue.py` 기본을 '헷갈리는 컷 + 군집마다 하나'로 바꾸고 `--work`(새 작품만), `--old`(예전 방식) 추가. 특징을 PCA 128로 줄여 큐 만들기 44분+ → 3분
