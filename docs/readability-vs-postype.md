## 떨어지는 지점 (영향이 큰 순)

### A. 색 대비

1. **흐린 글자색(대비 2.48)을 '읽어야 하는 정보'에 씀.** 포스타입은 본문에 거의 안 쓰고(대비 3 미만 1~2%), 우리는 화면 글자의 33~69%가 이 색이다. 해당 글자:
   - 상단 단계 메뉴의 비활성 단계명(캐릭터·세계관·구성·씬·콘티·작화): 모든 화면에서 늘 보임
   - 편집 레이어의 샷 라벨(중경·클로즈업…), 펼침 화살표
   - 씬 화면 컷 옆 ↑↓× 버튼, 인물 카드 '1컷 · 대사 1', 오른쪽 '등장인물·세계관' 머리
   - 에셋 패널 추천 근거('중경 · 아이레벨 · 평온 기준'), 판정 화면 '지금 DB 값: 클로즈업'(판단 근거인데 가장 흐림), 단축키 안내, kbd 번호
2. **보조 글자색(4.61)을 12px 이하에 씀.** 작은 글자는 같은 대비라도 더 안 읽힌다. 포스타입은 이 색을 주로 16~18px 부제·캡션에 쓴다. 해당 글자:
   - 에셋 탭·말풍선 이름(11.5~12.5px), 레이어 컷 이름(13px)
   - 상황 막대 라벨(12px: 아래 간격·그림 확대), 콘티 표 머리(12px)
   - 판정 진행 표시(12.5px)
3. **회색 고정값 #8a8f98(대비 3.25)이 섞여 있음.** 편집 캔버스의 씬 머리 '씬 1 · 창밖의 장미 · 러프'가 이 색이고, 색 토큰 밖의 값이다

### B. 글자 크기

4. **편집 화면은 글자의 69%가 13px 미만이고, 가장 흔한 크기가 12px다.** 포스타입 본문은 18px(휴대폰 16px)이다. 다음이 모두 11~12px다:
   - 상황 막대 버튼, 레이어, 에셋 라벨, 속성 서랍 라벨
5. **최소 글자 10~11px:**
   - 레이어 펼침 화살표 10px
   - 레이어 샷 라벨·작은 수 11px
   - 판정 kbd 11px
   - 에셋 썸네일 이름 11.5px
6. **콘티·작화의 내용 글이 15px/1.6.** 포스타입은 18px/1.75(휴대폰 16/1.67)다. 컷 장면 설명, 판정 화면 컷 내용(rvtext)처럼 '읽는 글'이 UI 라벨과 같은 급으로 처리되어 있다
7. **씬 화면은 원고 본문(16px/1.75)은 괜찮지만 주변 13px 미만이 27%(휴대폰 32%).** 도구 버튼 기호 `[ ]` `@` `-♪-`가 12px 굵게 쓰여 있다

### C. 위계·정리

8. **굵기 종류가 많음.** 포스타입 글은 4종(400/500/600/700)이고 우리는 5~6종이다. 씬 화면은 6종이다. 작은 글자를 굵게(12px b, 13px b) 강조하는 곳이 많아 위계가 굵기로만 갈린다
9. **크기 종류가 많음(휴대폰).** 포스타입 글은 5~6종이고 우리는 7~9종이다
10. **소제목이 내용보다 작거나 흐림.** 에셋 패널 소제목 h5(12px, 61%)가 그 아래 항목 이름과 비슷하거나 더 작다. 포스타입은 제목 32px/700, 부제 18px, 본문 18px로 단계가 분명하다
11. **편집 상단이 두 줄 막대(편집 막대 + 상황 막대), 둘 다 12~15px 버튼으로 빽빽함.** 포스타입 글 화면은 위가 한 줄, 아래에 떠 있는 동작 막대(좋아요·댓글·북마크)로 동작을 모았다

### D. 줄 길이·폭

12. **판정 화면의 컷 내용 한 줄이 80자(데스크톱).** 포스타입 본문은 39자에 고정 폭 약 700px 가운데 정렬이다. 오른쪽 열이 넓어 한 줄이 길어진다
13. **콘티·작화 표와 카드가 화면 폭을 따라 늘어남.** 글 영역의 최대 폭이 없는 곳이 있다. 포스타입은 본문 폭이 고정이다

### E. 휴대폰

14. **편집 상황 막대 글자가 서로 겹침(390px).** '그림 확대 100% 그림 편집 프레임 초기화 레퍼런스…'가 한 줄에 눌려 겹친다. 줄바꿈이나 가로 스크롤이 없다
15. **상단 단계 메뉴가 잘림.** 번호와 다음 단계명이 붙어 보이고('캐릭터 2 세계관'), 오른쪽이 잘린다('편집' 일부)
16. **상단 판정 버튼의 수 배지가 옆 '?' 버튼과 붙어 읽힘.** 간격이 4px 남짓이다
17. **포스타입 휴대폰 본문은 16px/1.67·22자인데, 우리 편집 시트(에셋)는 11.5~12.5px 라벨 중심**

### F. 기타

18. **영어 태그(작화)가 고정폭 글꼴 13~14px로 길게 이어짐.** 쉼표 뒤 줄바꿈이 없어 한 줄이 길다
19. **읽기 모드 상단이 작품명 대신 '읽기 모드'와 폭 버튼(360·390·430).** 포스타입 글은 시리즈명 → 제목(32px) → 부제 → 작가 순으로 머리를 구성한다

**바꾼 것**

- 최소 크기: 레이어 패널 13.5/12px, 상황 막대 13px(줄바꿈 없이), 에셋 탭·제목·항목 12.5~14px, 단축키 표시 12px

- 굵기: b·strong 600, h1·읽기 머리 700으로 정리(씬 화면만 아직 5종)
- 상단 단계 메뉴 번호와 이름 사이 간격, 휴대폰에서 단계 메뉴 가로 스크롤
- 읽기 모드 머리에 '읽기 모드' 대신 작품 제목

**남은 것:** 편집 화면은 12px 칸 번호·간격 표시·캔버스 위 작은 표시가 많아 13px 미만이 여전히 45%. 캔버스 안 표시(컷 번호, 간격 px)를 13px로 올리면 캔버스가 붐벼 보류.
