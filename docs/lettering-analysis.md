# 식자·말풍선 분석 (녹빛 레퍼런스 54장)

대상: `rough/references/green-midnight/` 39장 + `rough/references/creative/green-midnight-closeups/` 15장. 보류 중인 2장(7·8번)은 제외.
수치는 화면 폭 690px 기준.

## 말풍선

| 항목 | 관찰 | 툴 반영 |
|---|---|---|
| 바탕 | 순백이 아닌 크림·미색(#fbf8f1 근처). 장면 색에 맞춘 연두·회갈·살구 톤도 있음(GM-03-011, GM-02-007, GM-02-002) | 크림 `#fbf8f1` |
| 선 | 손그림 잉크선 2~3px, 살짝 흔들리고 이중선 느낌 | 2.2px 선 + 0.8px 어긋난 보조선 |
| 모양 | 보통=타원 / 당황·머뭇=울퉁불퉁(GM-06-015, 017) / 외침=뾰족 다각형(GM-06-016) / 속마음=구름 + 작은 원 사슬(GM-06-032) / 작은 말=작은 타원(“쉿.”, “……”) | 대사 괄호 지시·감정·문장부호로 5종 자동 선택 |
| 꼬리 | 가늘고 끝이 뾰족, 살짝 휨. 화자가 멀면 길게(GM-02-013, GM-06-016), 가까우면 짧게 | 화자 쪽으로, 최대 80px |
| 위치 | 패널 위쪽. 패널 윗변을 걸치거나(GM-06-012, 030, 034, 027, 024, 026) 패널 밖 여백에 두고 꼬리만 안으로(GM-06-009, 010, 015) | 위쪽 기본, 첫 말풍선은 윗변에 걸침 |
| 연속 대사 | 같은 화자 두 풍선을 잇거나 겹쳐 아래로(GM-06-026, 025) | 두 번째는 반대쪽 아래로 |
| 크기 | 패널 폭의 25~35%, 1~4줄, 줄당 4~9자 | 줄당 9자 줄바꿈, 최대 5줄 |
| 글자 | 21~26px 고딕 중간 굵기, 가운데 정렬. 짧고 센 말은 크고 굵게(GM-06-030 “너 코피나.”). 6화는 일부 인물 대사가 초록 글자 | 21px, 짧은 강한 대사 26px 굵게 |

| 글자만: 어두운 화면 위 밝은 글자, 아래 또는 위 가운데 | GM-05-011 “그날 이후.”, GM-05-018, 창작 07 | 여운(R) 컷, 효과 배경 컷 |

## 패널 배치

- 설정·분위기 컷은 테두리 없이 좌우 끝까지(GM-02-002, 013, 03-002, 04-002, 05-018) → 설정·효과 배경 컷은 끝까지.
- 인물 컷은 폭을 줄여 좌우로 밀거나(GM-06-009, 010, 013, 07-014) 기울인 칸(GM-06-015, 031, 032) → 디테일 인서트는 폭 72%로 좌우 번갈아.
- 칸 사이 여백은 대체로 100~350px. 아주 긴 여백은 드묾 → 화면 간격을 중요도 단계는 유지한 채 최대 약 360px로 압축.

## 아직 못 한 것

- 붓글씨 서체: 내보낸 PNG는 웹 서체를 못 쓰고 시스템 서체로 그려져서, 굵기·기울임으로만 흉내 냄.
- 인물별 대사 글자색, 기울인 칸, 말풍선 이어 붙이기.
