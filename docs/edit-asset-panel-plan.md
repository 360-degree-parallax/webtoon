# 편집 화면 오른쪽 = 에셋 전용 (미리캔버스·망고보드 참고 기획)

2026-11-23 · 기획만, 구현 전

## 1. 참고 서비스에서 확인한 것

근거는 검색 결과로 확인한 공식 도움말 문장까지다. 도움말 사이트(help.miricanvas.com, toon.mangoboard.net)는 이 세션 네트워크에서 열리지 않았고, 두 서비스를 직접 조작해 보지도 못했다. 아래에 없는 내용(메뉴 순서, 선택 시 툴바 모양 등)은 추측하지 않는다.

**미리캔버스**
- 사진·영상·업로드·오디오·내 리스트·배경·요소 메뉴가 모두 **에디터 왼쪽**에 있다
- 영상이나 차트를 고르면 투명도·자르기·볼륨, 종류·색·범례 같은 속성이 **왼쪽 속성창**에 나온다. 에셋 서랍과 속성창이 같은 쪽을 나눠 쓴다
- 업로드한 파일은 업로드 메뉴에 남아 다시 쓴다. '내 리스트'에 템플릿과 요소를 모아 둔다
- 배경 단색은 속성창이나 하단 바에서 정한다

**망고보드 / 망고툰**
- 왼쪽 배경 탭에서 색상·패턴·이미지·동영상을 고르고 [슬라이드 배경으로 설정]을 누른다. 테두리 같은 세부는 '배경편집'에서 바꾼다
- 동영상 소스는 슬라이드로 끌어 놓으면 바로 배경이 된다
- 이미지 프레임에 이미지를 끌어 놓으면 프레임에 맞춰 들어간다
- 망고툰은 텍스트 탭에 제목·디자인텍스트·**효과음**·텍스티콘이 있다(만화용). T 키로 텍스트를 바로 넣는다
- 업로드 메뉴에서 PC 이미지를 올린다

**공통으로 가져올 원칙**
1. 에셋은 **한 서랍, 한 곳**에 모으고, 종류는 탭으로 나눈다
2. 끌어 놓은 자리가 곧 적용 대상이다(프레임 안 → 그림, 빈 곳 → 배경)
3. 업로드와 즐겨찾기(내 리스트)를 같은 서랍에 두고 다시 쓴다
4. 속성은 무언가를 골랐을 때만 나온다

**우리와 다른 점:** 미리캔버스는 에셋과 속성이 같은 왼쪽을 번갈아 쓴다. 우리는 왼쪽에 이미 도구 막대와 레이어(목차)가 있다. 그래서 **오른쪽은 에셋 전용**으로 고정하고, 속성은 위쪽 상황 막대로 올린다.

### 3-1. 오른쪽 에셋 패널

- **검색창 하나로 모든 에셋을 검색:** 이름, 태그, 연출명(사전), 상세 분석 문구('하단 흰 여백' 등, 이미 만든 레퍼런스 상세 검색을 재사용)
- **적용 대상 칩:** "3컷 · 그림", "3↔4컷 사이", "말풍선 2"처럼 클릭이 어디에 들어갈지 늘 보여 줌. 망고보드의 '슬라이드 배경으로 설정'처럼 대상을 분명히 하는 장치
- **탭(가로 칩 두 줄):**

| 탭 | 내용(지금 있는 것에서 옮김) | 클릭 | 끌어 놓기 |
|---|---|---|---|
| **추천** | 고른 컷의 감정·샷·연출 패턴에 맞는 효과선·전환 질감·비슷한 레퍼런스·시퀀스 템플릿 (DB·학습 모델 활용) | 대상에 적용 | 놓은 자리에 적용 |
| 말풍선 | 형태 프리셋(일반·외침·속삭임·생각·나레이션 상자…) | 고른 말풍선의 형태 바꾸기 / 없으면 컷 가운데 새로 | 컷 안 그 자리에 새 말풍선 |
| 효과음 | 효과음 ZIP 615종(검색·변형), 직접 입력 | 대상 컷에 넣기 | 그 자리에 |
| 효과선 | 집중선·속도선 등(지금 '소재' 효과선) | 대상 컷에 | 그 자리를 중심으로 |
| 배경 | 전환 질감 7종, 단색 팔레트(씬에서 쓴 색 먼저), 업로드한 배경 이미지 | 대상 '컷 사이' 전환에 적용 | 컷 사이 간격에 놓으면 그 전환, 컷 안에 놓으면 컷 배경 |
| 컷 참고 | 레퍼런스(지금 왼쪽 패널) | 고른 컷의 레퍼런스 바꾸기 | 컷 위에 놓기(지금도 됨) |
| 시퀀스 | 저장한 시퀀스 템플릿 + DB 5컷 리듬 742개(연출명별) | 고른 컷부터 적용 | 컷 위에 놓으면 그 컷부터 |
| 업로드 | 배경 이미지·효과음 묶음·일반 이미지 한 곳 | 종류에 맞게 적용 | 위와 같음 |
| ★ | 즐겨찾기 + 최근 사용(지금 소재 즐겨찾기를 확장) | | |

- 고른 대상이 바뀌면 탭도 따라감: 말풍선을 고르면 말풍선 탭, 컷 사이를 누르면 배경 탭, 컷을 고르면 추천. 사용자가 탭을 직접 바꾸면 그 선택을 유지
- 미리보기: 마우스를 올리면 캔버스에 반투명 미리보기, 떼면 사라짐(효과선·전환 질감처럼 결과가 큰 것부터)

### 3-2. 오른쪽에서 빠지는 것의 새 자리

| 지금(오른쪽) | 새 자리 | 근거 |
|---|---|---|
| 속성 › 배경색·중간색·위치·이미지 진하기·씬 끝 색 | **컷 사이 간격을 누르면** 상황 막대가 '배경' 모드로 바뀌어 이 값들을 보여 줌. 고르는 것 자체(질감·이미지)는 에셋 '배경' 탭 | 망고보드 배경 탭(고르기) + 배경편집(세부) 구조 |
| 속성 › 레퍼런스 바꾸기 | 상황 막대에 지금 레퍼런스 이름. 바꾸기는 에셋 '컷 참고' | |
| 속성 › 그림 확대·프레임 초기화 | 상황 막대(일부 이미 있음) | |
| 속성 › 씬 전체 맞춤·씬 색 한 번에 바꾸기 | 상황 막대 끝 '씬 ▾' 메뉴 + 레이어 패널 씬 행의 … 메뉴 | 씬 단위 작업은 목차에서 |
| 속성 › 시퀀스 템플릿 저장 | 레이어 패널에서 여러 컷을 고른 뒤 … › '시퀀스로 저장'. 적용은 에셋 '시퀀스' | |
| 속성 › 말풍선 문구 | 캔버스에서 바로 고치기(더블클릭) + 상황 막대 문구 칸 | |
| 속성 › 말풍선 꼬리·형태 | 꼬리는 캔버스 손잡이(지금도 있음). 형태는 에셋 '말풍선' | |
| 글자 패널(글꼴·크기) | 상황 막대 글꼴·크기(말풍선을 골랐을 때). 작품 기본 글꼴은 '작품 설정' | |
| 정렬 패널 | 여러 개를 고르면 상황 막대에 정렬 버튼이 나타남 | 일러스트레이터 컨트롤 막대 방식(기존 기획과 같음) |
| 기록 패널 | 되돌리기 옆 ▾ 목록 | |
| 내비게이터 | 캔버스 오른쪽 아래 떠 있는 미니맵(M으로 켜고 끔) | |
| 소재 패널 | 에셋 패널로 흡수 | |
| 작업 공간 프리셋 3개 | '에셋 탭 기본값'으로 바꿈: 편집 = 추천, 식자 = 말풍선, 연출 참고 = 컷 참고 | 오른쪽 구성이 하나로 고정되므로 |
| 저장 실패·완성본 점검 | 지금처럼 위에 둠 | 작업물 경고는 늘 보여야 함 |

### 3-3. 상황 막대를 두 줄까지

- 1줄: 대상 칩 + 자주 쓰는 값 4~6개
- '더보기 ▾'를 누르면 2줄이 펼쳐짐: 나머지 값
- 대상별 구성

| 대상 | 1줄 | 2줄(더보기) |
|---|---|---|
| 컷 | 아래 간격·그림 확대·그림 편집·레퍼런스·잠그기 | 프레임 초기화·사선 칸·컷 배경색 |
| 컷 사이 | 간격·전환 질감 이름·배경색(위→아래) | 중간색·위치·배경 이미지 진하기·씬 끝 색 |
| 말풍선 | 문구·형태·글꼴·크기 | 꼬리 보이기·스타일 초기화 |
| 여러 개 | 정렬 6개·간격 맞춤 | 씬 전체 맞춤 |

## 6. 위험

- **속성 찾기:** 오른쪽 속성에 익숙한 사람이 헤맬 수 있음 → 처음 한 번 "속성은 위로 옮겼어요" 안내, 상황 막대 '더보기' 위치를 눈에 띄게
- **끌어 놓기 오판:** 컷 안인지 컷 사이인지 경계에서 잘못 판정할 수 있음 → 끄는 동안 놓일 자리를 미리 강조(파란 테두리 / 간격 띠)
- **패널 시스템과 충돌:** `workspace.js`의 패널 떼어 띄우기·옮기기·프리셋은 오른쪽이 고정되면 의미가 줄어듦 → 왼쪽(레이어·도구)에만 남기고 오른쪽은 고정
- **UX 비교 분기:** `?ux=A/B` 분기가 아직 남아 있음 → 4단계 정리를 먼저 하거나, 이 작업은 C안 위에서만
