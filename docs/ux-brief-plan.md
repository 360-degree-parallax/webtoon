## 1. 공통 준비

### 1-1. 고정 원고(픽스처)

- 툴의 기본 예시 씬 「창밖의 장미」(6컷)를 씀. 브리프의 '복도에서 마주치다'는 예시 문구로만 남김

### 1-2. 시안 전환

- 주소에 `?ux=A|B|C`(기본 A = 지금 화면). `document.body.dataset.ux`로 분기
- B는 대부분 문구 표(`UX_COPY[variant][key]`)와 CSS 숨김으로, C는 작화 화면 DOM 순서와 카드 마크업을 바꿔서 만듦
- 실험이 끝나면 고른 안만 남기고 분기를 지움(코드에 세 갈래를 오래 두지 않음)

### 1-3. 자동 측정 스크립트 `tools/ux_measure.js`

Playwright로 시안 3개 × 화면 2개(1280×900, 390×844) × 화면 3개(작화·콘티·씬)를 돌려 표로 냄.

### 1-4. 사용자 확인(시안별 5명 내외)

- 시안 순서는 사람마다 바꿈. 같은 사람이 A를 본 뒤 C를 보면 학습 효과가 생기므로 첫인상 질문은 처음 본 시안에만 함
- 질문 순서는 브리프 그대로: ① "어떤 종류의 서비스처럼 보였어요?" → ② "무엇을 보고 그렇게 느꼈어요?"

## 4. 2단계: 콘티 요약 (B 방식만)

### 4-1. 기본 화면

> **창밖의 장미**  
> 6컷 · 마지막 컷에서 터뜨려요.  
> [컷 순서 편집] [연출 근거]

- 제목은 사용자가 쓴 씬 제목
- 요약 한 줄은 서사 형태로 고르는 짧은 문장. 엔진 값은 그대로 쓰고 문장만 바꿈:

  | 서사 형태(화면 표기 · DB 코드) | 한 줄 |
  |---|---|
  | 끝 하이라이트 · 끝 정점 | 마지막 컷에서 터뜨려요 |
  | 중간 하이라이트 · 중간 정점 | {n}번 컷에서 가장 세게 가요 |
  | 하이라이트 먼저 · 정점 선행 | 첫 컷부터 세게 열어요 |
  | 하이라이트 연속 · 정점 연속 | 세게 몰아붙여요 |
  | 하이라이트 없음 · 무정점 | 고르게 흘러가요 |

- [연출 근거]를 누르면 지금의 '이렇게 읽었어요' 카드 전체가 그 자리에 펼쳐짐
  - 서사 형태·연출 목적·감정 곡선·템포·주된 전환
  - 일치율과 **일치한 항목**(지금 `서사 형태·감정 곡선·연출 목적·템포 일치`를 % 옆으로)
  - 참고 패턴과 다른 후보
- `감정·정점·연출 목적을 글에서 계산하고, 연출 DB 742묶음 중…`(설명 문단), `코드표 기준 자동 판정` → 삭제. 근거 패널 첫 줄에 한 번만

### 4-2. 컷 표 출처 반복 정리(검토 의견 2)

**지금:** 컷마다 값 아래 설명 줄이 붙어 있음. 6컷 × 5줄 ≈ 30줄. 예:
- `패턴 컷 HN-05-045 설정`
- `패턴 컷 앵글`
- `강도 0 · 템포 느림`
- `이야기를 이어감`
- `특별한 감정 낱말 없음`

**바꿈:**
- 기본은 값만 보임(구조 `I 전개`, 감정 `평온 ○○○`, 샷 `설정`, 앵글 `아이레벨`, 길이 `길게`)
- 행을 누르거나 키보드로 포커스하면 그 행만 설명 줄이 펼쳐짐(지금 문구 그대로 재사용)
- 사람이 직접 고른 값(● 표시)과 컷 사이 간격 표시(`↓ 붙임 · 같은 인물 연속 동작`)는 작업 판단에 쓰이므로 남김. 간격 설명 문구만 펼침으로
- 표 위 `값을 누르면 바꿀 수 있어요 · ● 직접 고른 값` → `● 직접 고른 값` 범례만

| 화면 | 지운 문구 | 옮긴 정보 → 여는 조작 | 남긴 경고 |
|---|---|---|---|
| 작화 | 설명 문단, 4단계, 보조 문구 3개, 이중 표기 | 모델·태그·품질 안내 → [작화 설정] / 생성 설정·좌표 → [프롬프트] / 전송 내용 → [Claude로 다듬기] 확인 창 | 원고 변경 후(→ [변경 확인]) |
| 콘티 | 설명 문단, '코드표 기준 자동 판정', 표 설명 줄 30개 | 판정·근거·일치 항목 → [연출 근거] / 컷 근거 → 행 펼침 | 직접 고른 값 표시 |
| 씬 | 쓰는 법 표, 아래 콘티 보기, 통계 일부 | 문법 → `?` / 통계 → 마우스 올리기 | — |

## 7. 진행 순서와 산출물

| 단계 | 할 일 | 끝났다고 보는 기준 |
|---|---|---|
| 0 | 픽스처, `?ux=` 분기, 측정 스크립트, 기준선 재측정 | A 수치가 표 1-3과 ±10% 안에서 재현됨 |
| 1a | 작화 B | 체크리스트 100%, 글자 목표 |
| 1b | 작화 C(+[변경 확인]) | 체크리스트 100%, 첫 컷·글자 목표 |
| 1c | 측정 + 사용자 확인 → 채택안 결정 | 성공 기준표 채움 |
| 2 | 콘티 요약 + 표 정리(B 방식) | 글자 목표, 컷 값 수정·연출 근거 열기 정상 |
| 3 | 씬 작성 안내 | 문법 도움말이 `?`에서 열림, 빈 컷 예시 |
| 4 | 채택안만 남기고 분기 정리, 변경 기록표 확정 | 분기 코드 0 |

**각 단계 산출물:**
- 비교 스크린샷(데스크톱·390px, A·B·C 같은 상태)
- 측정 표
- 변경 기록표

## 8. 위험과 대응

- **도움말을 숨기면 처음 쓰는 사람이 막힘:** 빈 상태(이미지 0장, 빈 컷)에서만 한 줄 안내를 남기고, `?` 도움말 창에 지운 내용을 모두 옮김. 지운 문구가 어디에도 없게 되는 일은 없게 함
- **분기 코드가 남음:** 4단계에서 반드시 정리. 측정 스크립트는 남겨 이후 화면 변경 때 회귀 측정에 씀
- **요약 한 줄이 장면과 안 맞는 문장을 낼 수 있음:** 서사 형태별 문장을 엔진 평가셋(742묶음)의 대표 사례에 붙여 보고 어색한 문장을 고침
