| 지운 문구 | 옮긴 정보 → 여는 조작 |

| 제목 옆 `NovelAI V4.5 Full`, 설명 문단, 4단계 사용법 | 모델 → [작화 설정] 서랍 첫 줄 |
| `화풍 태그` 보조 문구, Add Quality Tags 안내 | 보조 문구 → 입력칸 placeholder / 안내 → 작화 설정 안 |

| `레퍼런스` 섹션(캐릭터·장면 이미지와 같은 정보) | C: 숨김(이미지 상태는 작화 설정의 '캐릭터·장면 이미지' 한 줄) |

| `컷별 입력값`, `이미지 0/6컷 등록 · 칸마다 복사 버튼` | 상단 칩 `이미지 3/6` |
