    컷

      완성

      이 씬을 어떻게 완성할지 골라요. 씬마다 다르게 골라도 돼요. 고른 방식은 웹툰 보기에 쓰여요.

      3D 시안

      컷 배치에서 계산한 샷·앵글·감정·행동으로 VRoid 기본 체형을 흑백 툰으로 그려요. 장면 글을 고치면 다시 그리기를 눌러주세요.

      배역

      인물마다 체형을 골라요

      컷

      컷 배치 탭의 값을 그대로 써요

      다시 그리기를 누르면 여기 그려져요

      프롬프트 시안

      컷 배치에서 정한 샷·앵글·감정·동작에 인물 외형과 화풍을 묶어 컷마다 구체적인 프롬프트를 만들어요. 생성한 이미지를 컷 옆에 올리면 웹툰 보기에서 완성본으로 이어져요.

      1. 1화풍·참고 이미지
      2. 2프롬프트 복사해 생성
      3. 3만든 이미지를 컷에 등록
      4. 4웹툰으로 보기

      화풍

      모든 컷 프롬프트에 똑같이 들어가요 · 이 브라우저에 저장

      참고 이미지

      끌어다 놓기·붙여넣기·클릭 · 이 브라우저에만 저장돼요
      캐릭터장면 글의 인물 이름과 자동 연결
      장면배경·분위기. 색이 프롬프트에 들어가요

      Claude로 다듬기

      씬 전체를 읽고 연속성·구도·몸 표현을 추론해 컷 프롬프트를 다시 써요

      내 API 키로 이 브라우저에서 바로 호출해요(Claude Opus 5.5). 키는 이 브라우저에만 저장되고, 씬 글·인물 외형·화풍만 보내요. 이미지는 보내지 않아요.
