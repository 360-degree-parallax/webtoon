      완성

      이 씬을 어떻게 완성할지 골라요. 씬마다 다르게 골라도 돼요. 고른 방식은 웹툰 보기에 쓰여요.

      NovelAI V4.5 시안

      NovelAI Diffusion V4.5 Full 기준이에요. 컷마다 기본 프롬프트, 캐릭터 프롬프트와 위치, 제외할 내용, 해상도, img2img 바탕 이미지, 레퍼런스를 칸별로 나눠 줘요.

      1. 1화풍·인물 태그 확인
      2. 2컷 카드의 칸을 NovelAI 같은 칸에 복사
      3. 3바탕 PNG를 img2img로 올려 생성
      4. 4생성 이미지를 컷에 등록

      화풍 태그

      모든 컷의 기본 프롬프트 끝에 붙어요 · 영어 태그, 쉼표로 구분

      NovelAI의 Add Quality Tags와 제외할 내용 프리셋(Heavy)은 켜 두는 걸 권해요. 여기 태그는 그 위에 더해져요.

      프롬프트 시안

      컷 배치에서 정한 샷·앵글·감정·동작에 인물 외형과 화풍을 묶어 컷마다 구체적인 프롬프트를 만들어요. 생성한 이미지를 컷 옆에 올리면 웹툰 보기에서 완성본으로 이어져요.

      1. 1화풍·참고 이미지
      2. 2프롬프트 복사해 생성
      3. 3만든 이미지를 컷에 등록
      4. 4웹툰으로 보기

      참고 이미지

      끌어다 놓기·붙여넣기·클릭 · 이 브라우저에만 저장돼요
      캐릭터장면 글의 인물 이름과 자동 연결
      장면배경·분위기. 색이 프롬프트에 들어가요

      Claude로 다듬기

      씬 전체를 읽고 연속성·구도·몸 표현을 추론해 컷 프롬프트를 다시 써요

      Claude API(Opus 5.5) 전용이에요. 키는 보안 입력창에서만 받고, 화면에는 끝 네 자리만 보여요. 씬 글·인물 외형·화풍만 보내고 이미지는 보내지 않아요.

      Claude API 키

      Anthropic Claude API 키만 받아요. 키는 api.anthropic.com으로만 전송되고, 이 페이지는 보안 정책으로 다른 서버에 연결할 수 없어요.

      보관

      모델 Claude Opus 5.5 고정 · 저장 전에 키가 맞는지 Anthropic에 확인해요(토큰 비용 없음) · 키 발급은 Claude Console의 API Keys
