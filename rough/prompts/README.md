# 이미지 프롬프트

Node.js 18 이상에서 저장소 루트 기준으로 실행합니다.

```bash
node rough/prompts/serve.js
```

[http://127.0.0.1:8002/rough/prompts/](http://127.0.0.1:8002/rough/prompts/)에서 사용합니다. 포트를 바꾸려면 마지막 인자로 번호를 붙입니다. 기존 러프 툴과 함께 실행할 수 있습니다.

장면은 한 줄에 한 컷씩 입력합니다. `인물 | 행동 "대사" [내레이션: …] [효과음: …] [구도: …]` 형식이며 필요한 요소만 쓰면 됩니다. 캐릭터 설정에는 `인물 | 외형과 의상` 형식으로 인물을 구분할 수 있습니다.

서버는 기존 연출 엔진과 저장소의 참고 컷 목록을 읽어 이미지 프롬프트, 식자 지시, 폭 690px 기준의 배치 좌표를 계산합니다. 참고 컷은 원본 ID가 일치하면 먼저 적용되고, 컷별로 직접 바꿀 수도 있습니다. 원본 기반 러프와 창작 참조는 목록에서 이름으로 구분됩니다.

생성용 텍스트는 TXT로, 컷 위치와 식자 좌표는 JSON으로 내려받을 수 있습니다. 입력은 실행 중인 로컬 서버에서 처리합니다.

## 참고 컷과 편집

컷을 열고 참고 이미지를 직접 고르면 **구도**, **색·빛**, **컷 길이**를 각각 켤 수 있습니다. 구도는 카메라와 인물 배치, 색·빛은 그림 안의 색과 명암, 길이는 출력할 컷 높이에 적용됩니다. 장면 줄에 `[구도: …]`를 써둔 경우 그 문장이 참고 컷의 구도 묘사보다 우선합니다.

그림 프롬프트는 바로 수정할 수 있습니다. **이 컷 확정**을 누르면 문장과 카메라 구도, 컷 높이와 뒤 여백을 고정합니다. 다른 컷이 움직일 수 있어 전체 스크롤의 절대 Y 좌표는 재계산합니다. 같은 장면 줄을 옮겨도 편집 내용이 따라갑니다. 줄 자체를 바꾸면 새 컷으로 처리합니다. 장면과 편집 상태는 같은 주소의 같은 브라우저에서 다시 열 수 있습니다.
