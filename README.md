# webtoon

웹툰 연출을 컷 단위로 분석해 DB로 만들고, 그 DB를 연출 문법으로 삼아 **설정집 → 구성 → 씬 → 콘티 → 편집** 순서로 세로 러프 원고를 만드는 도구 모음입니다.

배포본: GitHub Pages(`main` 브랜치) · 로컬: `python3 rough/serve.py` → `http://localhost:8000/rough/`

| 폴더 | 내용 |
|---|---|
| `rough/` | 러프 툴(웹). 엔진 `engine.js`, 화면 코드 원본 `rough/src/`(빌드해서 `app.js`), Claude 연동 `claude.js`, 구성 `composition*.js`, 프롬프트 `prompt.js`·`nai.js`, 내보내기 `export.js` |
| `rough/db/` | 연출 DB 사본 `db.json`, 사람이 확인한 라벨 `verified.json`, 판정 큐 `review-queue.json` |
| `analysis/` | 원본 회차를 컷으로 나누고 판정하는 파이프라인 |
| `tools/` | DB 동기화·검사·빌드 스크립트, `tools/ml/` 머신러닝(임베딩·판정 큐·실험) |
| `docs/` | 코드표(`codebook.md`), 툴 설계와 변경 기록(`rough-plan.md`), ML 결과(`docs/ml/`) |
| `tests/` | 브라우저 회귀 테스트(`tests/e2e/run.js`) |
| `cuts/` | 원본 컷 이미지 (비공개 서브모듈, 저장소에 원본을 올리지 않음) |

## 받기
```bash
git clone --recurse-submodules https://github.com/360-degree-parallax/webtoon
```
`cuts/`는 비공개 저장소라 권한이 있어야 받아집니다. 없으면 비어 있고 나머지 기능은 그대로 씁니다. 이미 받았다면 `git submodule update --init --depth 1`.

## 러프 툴

### 화면 흐름 (위 단계 탭)
1. **설정집**: 캐릭터(이름·호칭·체형·외형·참고 이미지)와 세계관(장소·소품). 글에서 `@이름`으로 불러 씀. 등장인물은 회차마다 따로 정하고, 설정한 인물은 캐릭터 보관함에 자동으로 들어가 다른 회차에서 「이 회차에 넣기」로 불러 씀
2. **구성**: 작품 개요를 넣으면 Claude가 회차 구성안(장면 카드)을 만듦
   - 카드마다 **다시 생성**을 누르면 "어떻게 다시 만들지" 적는 칸이 열림(Enter 생성 · Esc 닫기, 적은 말은 남음)
   - 생성이 끝나면 Claude가 구성안에서 설정집에 없는 인물·엑스트라·장소를 찾아 "어떤 장면의 누구를 캐릭터/세계관에 추가할까요?" 창을 띄움 → 고른 것만 자동 추가
3. **씬**: 씬마다 컷 글 입력(`[식자]`, `-효과음-`, `@인물 "(감정)대사"`, `#소품`, 나머지는 행동 묘사). 소품은 처음 나올 때 `#회중시계(금색, 뚜껑에 장미 문양)`처럼 형태를 적으면 세계관 물건으로 등록되고, 그 뒤 모든 컷 프롬프트에 같은 형태·태그로 고정됨. 감정·정점·연출 목적을 계산하고 DB에서 가장 닮은 5컷 패턴을 고름. 문장은 절 단위로 읽어 누가 무엇을 했는지(안 한 동작·하려다 만 동작은 빼고, '그/그녀'는 앞 컷 인물로) 컷 프롬프트에 넣고, 쓰는 중에 '누가?'·'동작 2개 → 컷 나누기' 같은 알림을 띄움
4. **콘티**: 컷 표 + 러프 미리보기 + 컷별 이미지 프롬프트(자연어 / NovelAI 태그)
   - 컷 프롬프트 생성 중·완료가 버튼과 컷마다 표시됨
   - **컷 상세 수정**: 컷 하나의 샷·앵글·감정·칸 높이를 직접 고르고, 요청을 적어 그 컷 프롬프트만 다시 생성. "자동으로"로 되돌림
   - **컷 지우기**: 씬·편집 화면과 연동, Ctrl+Z로 되돌림
   - **요소별 레이어로 뽑기**: 컷 한 장 대신 배경(늘 따로)·인물마다·두 명 이상이면 함께 있는 장면(상호작용, NovelAI 여러 인물 칸) 프롬프트를 따로 만들고, 넣은 그림을 레이어로 겹침(흰 배경 자동 제거). 소품은 든 인물이나 배경에 녹여 넣고, 필요하면 따로 레이어로. 같은 장소 배경·같은 자세 인물은 한 장을 같이 써서 고정. 편집에서 레이어별로 옮기고 PSD에도 레이어 하나씩
   - **컷 비율 기준**: 상용 웹툰 9작품의 실측 칸 비율(작품별·전체) 중 골라 칸 길이를 맞춤(`rough/ratio-profiles.js`)
5. **편집**: 세로 캔버스에서 말풍선·나레이션·효과음·칸 모양·배경·레이어 편집, 읽기 모드, 대사 교정. PNG·SVG(피그마)·PSD(클립스튜디오) 내보내기

### 상단 버튼
- **초기화**: 작업 전체를 처음 상태로. 직전 상태는 저장 보관함에 자동으로 남음
- **저장**: 지금 작업을 이름 붙여 브라우저 보관함(IndexedDB)에 임시 저장 · 목록에서 불러오기/지우기
- **내보내기**: 회차 백업 파일·이미지·SVG·PSD
- **DB**: 연출 DB 조회, 레퍼런스 검색, 판정 화면(모델이 헷갈리는 컷을 사람이 고르는 큐)
- 설정집(캐릭터·세계관)·구성·씬 화면마다 작은 **초기화** 버튼(8초 안에 되돌리기 가능)

Claude 기능은 내 Anthropic API 키를 넣으면 켜집니다. 키와 첨부 이미지는 브라우저에만 저장됩니다.

### 개발
화면 코드는 `rough/src/`를 고치고 빌드합니다(`rough/app.js`를 직접 고치지 않음).
```bash
python3 tools/build_app.py
```
```bash
node tests/e2e/run.js
```
```bash
node rough/test_engine.js
```
e2e는 Playwright로 정적 서버를 직접 띄워 시나리오를 돕니다. GitHub Actions: `e2e.yml`(rough·tests 변경 때), `db-check.yml`(DB·도구 변경 때).

## 머신러닝
- 그림(CLIP·DINOv2)·글(E5) 임베딩으로 샷·앵글·역할·감정 모델, 연출명 추천, 칸 길이·간격, 말풍선 모양, 묶음 판정 등을 학습해 툴에 씀. 평가는 한 작품을 빼고 학습하는 방식(누수 방지)
- 실험 6종(사전학습 비전 특징, 라벨 오류 찾기, 능동 학습, 자기지도 순서 모델, 5컷 묶음 군집, 제로샷)과 적용 결과: `docs/ml/exp/README.md`
- 판정 큐(`tools/ml/make_review_queue.py`): 모델이 헷갈리거나 사람 라벨과 어긋나는 컷을, 비슷한 컷이 몰리지 않게 군집마다 골라 사람이 판정. 고른 값은 `verified.json`에 남아 다음 학습에서 가중치가 커짐
- 지금까지 Claude가 원본 컷을 직접 보고 검수한 판정 큐 1,442항목: 샷 717(319 수정) · 앵글 85(26) · 역할 320(93) · 감정 320(17). 확인 기록 2,948건
