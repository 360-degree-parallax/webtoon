# webtoon

웹툰 연출을 분석해 DB로 만들고, 그 DB를 연출 문법으로 써서 러프를 만드는 도구 모음입니다.

| 폴더 | 내용 |
|---|---|
| `analysis/` | 기존 웹툰 회차를 컷 단위로 나누고 샷·앵글·역할·감정·색·5컷 리듬을 기록하는 파이프라인 |
| `rough/` | 장면 글만 넣으면 감정·정점·연출 목적을 계산하고 DB에서 가장 닮은 5컷 패턴으로 세로 러프를 그리는 웹 툴. 엔진은 `rough/engine.js`, 설계는 `docs/rough-plan.md` |
| `docs/codebook.md` | 두 쪽이 함께 쓰는 코드표와 판정 규칙 |
| `cutlink.py` | 컷 ID로 원본 컷 이미지를 찾는 함수 (`cuts/` 필요) |
| `cuts/` | 원본 컷 이미지 (비공개 저장소 `webtoon-cut` 서브모듈) |

## 받기
```
git clone --recurse-submodules https://github.com/360-degree-parallax/webtoon
```
`cuts/`는 비공개 저장소라 접근 권한이 있어야 내려받아집니다. 권한이 없으면 비어 있고, 나머지 기능은 그대로 쓸 수 있습니다. 이미 받았다면 `git submodule update --init --depth 1`.

## 러프 툴 실행
```
python3 rough/serve.py
```
`http://localhost:8000/rough/` 가 열립니다. 장면만 적으면 판정·패턴·컷 배치가 자동으로 나오고, 틀린 값만 눌러서 고치면 됩니다. 캐릭터·장면 참고 이미지를 첨부하면 밑그림·이름표·컷별 이미지 프롬프트(자연어)에 쓰입니다. 내 Anthropic API 키를 넣으면 Claude가 씬 전체를 읽고 프롬프트를 다듬습니다. 생성한 이미지를 컷마다 등록하면 웹툰 보기에서 완성본으로 이어집니다. 첨부 이미지는 브라우저에만 저장됩니다.

화면 흐름 (위 단계 탭):
1. **작성**: 인물 설정(이름·호칭·체형·외형) + 씬 목록 + 씬마다 컷 입력(`[식자]`, `-효과음-`, `@인물 "(감정)대사"`, 나머지는 행동 묘사)
2. **연출**: 씬별 판정·패턴·컷 표·러프 미리보기, 값 고정
3. **완성**: 씬마다 3D 시안(VRoid CC0 흑백 툰, `rough/toon3d.js`) 또는 프롬프트 시안(`rough/prompt.js`, 컷별 프롬프트 + 생성 이미지 등록) 선택
4. **웹툰 보기**: 모든 씬을 이어 한 편으로 세로 조회(완성본/러프 전환: 완성본은 등록 이미지 → 3D → 러프 순, 이미지 저장)

상단 바의 **DB** 버튼: 연출 DB 시트 조회 (`rough/db/db.json`). 컷 썸네일은 비공개 `cuts/`가 있을 때만 보임.

엔진 판정 검증:
```
node rough/test_engine.js
```

## 컷 이미지 찾기
```
python3 cutlink.py GM-03-045
```

`rough/patterns.json`은 이두나!(DN)·녹빛자정의 연인(GM) 1~7화 244개 묶음의 구조 통계(샷·앵글·역할·감정·강도·컷 높이·여백 비율)를 담습니다. `rough/db/db.json`에는 시트 전체(컷 내용·메모 포함)가 들어 있습니다. 원본 컷 이미지는 비공개 `cuts/`에만 있습니다.

## 상태
- 분석: 두 작품 1~7화 완료 (1,497컷, 244묶음)
- 러프 툴: v1. 선택 없이 연산으로 러프 생성, 결과물(그림) 형태는 개발 중
